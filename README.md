# alu-system_engineering-devops

System engineering and DevOps practice projects: SSH key-based server
access, Bash scripting, and basic web server configuration.

## ssh/
Scripts for connecting to and managing a remote server over SSH.

- `0-use_a_private_key`: connects to the assigned server using the
  RSA private key at ~/.ssh/school.

## web_server/
Scripts for configuring and deploying to the assigned web server.

- `0-transfer_file`: transfers a file to a remote server's home
  directory using scp.
